## Why

После `/start` основной вход в разделы — только инлайн-кнопки под сообщением. У поля ввода Telegram уже есть Menu Button (бургер), но бот не регистрирует осмысленный список команд, поэтому нативная поверхность почти пустая. Нужно заполнить её командами разделов и help, сохранив инлайн как главное меню, и показывать `/admin` в бургере только админам.

## What Changes

- Бот регистрирует список команд Telegram (Menu Button → commands): `/start`, разделы, `/help`; у админов дополнительно `/admin`.
- Появляются слэш-команды разделов с тем же смыслом и gate, что у инлайн-кнопок; подписи в меню с эмодзи как у inline.
- `/help` кратко объясняет бота и перечисляет доступные команды (у админа — с `/admin`).
- На `/start` список команд целевого чата синхронизируется (admin vs learner, в т.ч. для banned) до ответа.
- После назначения или снятия админа список команд у целевого пользователя обновляется сразу (ban/unban список команд не трогает; demote = явный learner-список на чат, не «просто удалить»).
- `/help` отвечает без обязательного `/start` (в т.ч. banned); слэш разделов/`subscription` — сначала unregistered → «Сначала нажми /start», иначе те же ban/gate правила, что у inline для зарегистрированных.
- Инлайн-меню под приветствием не убирается и остаётся основным UX разделов.

## Scope

- **Capability ID:** `start/register`, `admin/panel`
- **Пакет:** bot (`my-study-bot`)
- **UX:** русский текст; Menu Button = список команд (не Mini App, не reply-клавиатура); инлайн-меню сохраняется
- **Команды learner:** `/start`, `/cars`, `/houses`, `/computers`, `/subscription`, `/help`
- **Команда admin:** `/admin` только в меню команд админов; отказ не-админу по-прежнему
- **Описания команд:** разделы — эмодзи + те же формулировки, что у inline («🚗 Машины» и т.п.); `start`/`help` — короткие RU без эмодзи разделов (канон в design)
- **Нативный Start** до первого `/start` — поведение клиента Telegram, без отдельной кастомной кнопки в коде

## Out of scope

- Mini App / `MenuButtonWebApp`
- Reply-клавиатура как замена бургера или inline
- Изменение иконок/подписей самих inline-кнопок (кроме согласованности описаний команд)
- Оплата, новый study-контент, смена gate/тарифов/expiry
- Кастомная отрисовка «бургера» вне Telegram Menu Button
- Команда `/settings` и прочие глобальные команды Telegram сверх согласованного списка

### Modified Capabilities

## Impact

- Пакет bot: поверхность команд Telegram, ответы на слэши разделов/help, синхронизация меню команд на `/start` и при смене роли админа
- Зависимости и инфраструктура не меняются (Bot API уже в aiogram)
- Пользовательский путь через inline не ломается; бургер — параллельный вход
