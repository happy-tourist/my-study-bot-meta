## Why

Оператору нужен контур управления внутри Telegram: статистика пользователей, бан/разбан, назначение админов и ручное продление подписки. Сейчас такого контура нет — только learner UX и фоновый expiry.

## What Changes

- Команда `/admin` и кнопка «Админ» в стартовом меню только для админов.
- Bootstrap-админы из env + роли админа в данных пользователя; назначение/снятие с карточки пользователя.
- Бан с полным закрытием доступа («доступ закрыт»), разбан, запрет банить админов.
- Статистика, списки с пагинацией, поиск по id / `@username`, карточка пользователя.
- Продление подписки теми же тарифами, что у learner; снятие подписки с карточки.
- Capability ID: **`admin/panel`** (новый домен, согласован в explore); затронуты **`start/register`**, **`subscription/gate`**.

## Scope

- Пакет: **bot** (`my-study-bot`).
- Capabilities: **`admin/panel`** (новый), **`start/register`**, **`subscription/gate`**.
- Доступ в админку: bootstrap id `463353358` (+ список в env) или флаг админа у пользователя, уже прошедшего `/start`.
- UX: русский; у админа в главном меню кнопка «Админ»; не-админ на `/admin` получает «доступ закрыт».
- Статистика: агрегаты по пользователям (всего, с активной подпиской, trial, забаненные и т.п. — детали в specs).
- Пользователи: пагинация списков + поиск; карточка с действиями admin / ban / unban / продлить тарифом / снять подписку.
- Защиты: админ не банит админа; нельзя снять админа с себя и с bootstrap; забаненного нельзя назначить админом до разбана.
- Бан: полный блок learner-действий с текстом «доступ закрыт».

## Out of scope

- Веб-админка, отдельный HTTP API.
- История платежей / ledger покупок (платежей ещё нет).
- Массовая рассылка, audit log, CSV-экспорт.
- Сброс `trial_used` админом.
- Свободный ввод дней/минут для продления (только кнопки существующих тарифов).
- ЮKassa и смена минутного harness expiry.

## Capabilities

### New Capabilities

- `admin/panel`: операторская панель — статистика, поиск/списки с пагинацией, роли админа, бан/разбан, продление и снятие подписки с защитами.

### Modified Capabilities

- `start/register`: у админа в главном меню появляется вход в админку; забаненный пользователь на `/start` получает закрытие доступа.
- `subscription/gate`: забаненный пользователь не проходит в тематические разделы (отказ «доступ закрыт», не путать с отказом «нужна подписка»).
