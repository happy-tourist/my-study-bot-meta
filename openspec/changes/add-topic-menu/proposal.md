## Why

После `/start` пользователь получает только приветствие без навигации по разделам. Нужна простая оболочка меню (темы + подписка), чтобы дальше наращивать контент без переделки входа.

## What Changes

- После успешной регистрации/приветствия на `/start` бот предлагает выбрать раздел через инлайн-меню.
- Разделы «Машины», «Дома», «Подписка» открываются по нажатию и показывают заглушечный текст.
- Из раздела можно вернуться в главное меню тем же сообщением (без спама новых сообщений).

## Scope

- **Capability ID:** `start/register`
- **Пакет:** bot (`my-study-bot`)
- **UX:** русский текст; one-shot callback-навигация (без FSM)
- **Решение по темам:** «Машины» / «Дома» — временные заглушки до отдельного study-change
- **Решение по подписке:** кнопка ведёт на stub-экран, без gate и без чтения статуса подписки
- **Решение по callback:** стабильные namespaced идентификаторы действий меню (детали — в design)

## Out of scope

- Реальный контент уроков / study flows (`study/lesson`)
- Проверка и отображение `subscription_end` / `is_active`, оплата, продление (`subscription/gate`)
- Reply-клавиатура как постоянное меню
- FSM-диалоги, новые модели БД, изменения middleware / deploy
